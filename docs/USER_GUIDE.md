# CommunityXP User Guide

## Overview

CommunityXP is a gamification platform that transforms your Whop community into an engaging, rewarding experience. Members earn XP for participating, unlock badges, complete quests, and climb the leaderboard.

---

## Getting Started

### For Community Owners

1. **Install CommunityXP** from the Whop App Store
2. **Configure your rewards** in Admin Panel → Reward Actions
3. **Set up quests** to guide member engagement
4. **Customize branding** (Elite tier) with your logo and colors

### For Members

1. **Log in daily** to earn XP and build your streak
2. **Complete quests** for bonus XP rewards
3. **Earn badges** by hitting XP and streak milestones
4. **Spend XP** in the store on power-ups and cosmetics

---

## Core Features

### 🎯 XP System
Members earn XP for community actions:

| Action | Default XP |
|--------|-----------|
| Daily Login | 10 XP |
| Complete Lesson | 50 XP |
| Forum Post | 5 XP |
| Chat Message | 5 XP |
| Start Course | 25 XP |
| Complete Course | 100 XP |
| Subscription Renewal | 200 XP |

*All XP values are customizable in Admin Panel → Reward Actions*

### 🔥 Streaks
- Log in on consecutive days to build your streak
- Miss a day? Your streak resets to 0
- **Streak Freezes** protect your streak (available in store)
- Earn milestone badges at 3, 7, 30, and 100 days

### 🏆 Badges
Badges are earned automatically when you hit milestones:

**XP Badges:**
- XP Novice (100 XP)
- XP Adept (1,000 XP)
- XP Veteran (5,000 XP)
- XP Master (10,000 XP)

**Streak Badges:**
- 3 Day Streak
- 7 Day Streak
- 30 Day Streak
- Century Club (100 days)

### 📋 Quests
Quests are challenges that reward bonus XP:
- **Getting Started** - Complete first actions
- **Content Explorer** - Engage with lessons
- **Weekly Warrior** - Stay consistent

*Admins can create custom quests in Admin Panel*

### 🛒 Store
Spend your XP on:
- **XP Boost** - 1.5x XP for 24 hours
- **Streak Shield** - Protect streak for 48 hours
- **Cosmetics** - Frames, titles, effects

### 📊 Leaderboard
Compete with other members! Leaderboard ranks by total XP.

## Admin Panel Guide

### Accessing Admin Panel
Click the menu icon → **Admin** (visible only to admins)

### Sections

| Section | Purpose |
|---------|---------|
| **Dashboard** | Member stats, sync status |
| **Members** | View/edit member profiles, XP, roles |
| **Reward Actions** | Configure XP for each action type |
| **Quests** | Create/edit quests and tasks |
| **Badges** | Configure badges and triggers |
| **Store** | Manage store items and pricing |
| **Settings** | White-label branding, community name |

### Managing Reward Actions
1. Go to Admin Panel → Reward Actions
2. Click "Add Action" or edit existing
3. Set the action type and XP value
4. Toggle active/inactive as needed

### Creating Quests
1. Go to Admin Panel → Quests
2. Click "Create Quest"
3. Set title, description, XP reward
4. Add tasks (e.g., "Log in 7 times")
5. Save and activate

## XP Sync Feature

CommunityXP automatically syncs your Whop activity:
- **Chat messages** from Whop chat
- **Forum posts** and replies
- **Course progress** and completions

### How to Sync
1. Click **Sync Activity** on the Dashboard
2. Wait for sync to complete
3. XP is awarded for recent activity

*Sync has a 30-minute cooldown to prevent spam*

## Troubleshooting

### "My streak reset unexpectedly"
- Streaks reset if you miss a calendar day (UTC timezone)
- Check your last_action_date in your profile
- Purchase Streak Shield to protect future streaks

### "My XP didn't update"
- Try clicking Sync Activity on Dashboard
- Check if the action type is enabled in Reward Actions
- Contact admin if issue persists

### "Quest progress not updating"
- Ensure the action type matches the quest task
- Progress updates on next action, not retroactively

## FAQ

**Q: Can I be in multiple communities?**
A: Yes! You have separate profiles, XP, and progress in each community.

**Q: What timezone are streaks based on?**
A: UTC (Coordinated Universal Time)

**Q: Can admins give XP manually?**
A: Yes, admins can edit member XP in Admin Panel → Members

**Q: How do I report a bug?**
A: Contact your community admin or reach out to CommunityXP support.
